# True Skate capture dataset

Store each replay in `data/raw/<dataset_name>/metadata.json`, `cam01.mp4`, `cam02.mp4`, ..., `cam_holdout.mp4`. Alternatively declare a numbered holdout such as `cam07` in metadata. Use at least two training cameras plus one holdout; six training views are the initial target. Copy `configs/datasets/metadata.template.json` and fill actual trick, replay ID, FPS (number or rational string such as `60000/1001`), resolution `[width,height]`, notes and capture properties. Null FPS/resolution means unknown until probing; no measurement is fabricated.

`camera_mode` is `fixed`, `follow`, `orbit`, or `custom`; `camera_motion` must be explicitly `fixed` or `moving`. UI labels alone cannot establish motion: a custom camera can move or stay fixed. `holdout_camera` names a video stem. `FIXED_CAMERA` and `MOVING_CAMERA` are the conceptual modes corresponding to these motion values.

Extracted format: `data/frames/<name>/cam01/frame_00001.jpg`, `frame_00002.jpg`, etc., plus copied `metadata.json` and generated `extraction.json`. The manifest records each source's rational FPS, dimensions, decoded frame count, extracted count, common interval, and common **one-based source frame indexes**. With interval 3, output 00001/00002 map to source frames 1/4. Naming remains contiguous for upstream compatibility. Normalized upstream time is `i/N`, not `i/(N-1)`; preserve the same convention for all training and evaluation views.

Extraction does not resample, trim unequal clips, infer offsets, or fix VFR. FFprobe decodes frame timestamps and rejects variable/discontinuous timing and disagreements between views; FFmpeg selects the same source indexes with passthrough timing. Every source must already cover exactly the same replay interval with identical counts, FPS and resolution. Timestamp matching uses a 0.1 ms tolerance; equal timing cannot prove equal replay state. Output directories must not exist; partial failures remain for inspection and require a new destination for retries. These scripts trade probe speed for timing validation and are intended for short trick clips.

Validation checks all images, consecutive names, counts, manifest agreement, dimensions, source FPS, motion and holdout existence. Contact sheets support visual synchronization checks. JPEG conversion is lossy; keep original videos outside Git and record any future encoding changes in the decision log. Raw data, extracted images, processed reconstructions and models are ignored. No True Skate dataset is included.
